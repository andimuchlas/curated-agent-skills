# Changelog Generator Skill

Transforms git commit histories and pull requests into structured, user-centric release notes.

## 1. Transformation Guidelines
- Translate internal technical jargon into customer-facing value statements.
- Group items into standard Keep-a-Changelog categories:
  - 🚀 **Features**: New functionality delivered to users.
  - 🐛 **Bug Fixes**: Resolved defects and regressions.
  - ⚠️ **Breaking Changes**: Action required by developers or API consumers.
  - ⚡ **Performance & Refactoring**: Speedups and stability improvements.
