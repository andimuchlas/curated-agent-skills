# Frontend Slides Skill

Constructs interactive, presentation-ready HTML/CSS slide decks for pitch decks, technical talks, and architecture reviews.

## 1. Deck Features
- Keyboard navigation (Arrow keys, Spacebar, Home/End).
- Fullscreen mode (`F` key) and presenter view with speaker notes.
- High-contrast typography and syntax-highlighted code slides.
