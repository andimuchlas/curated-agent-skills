# D3.js Visualization Skill

Best practices for building responsive, performant, and interactive data visualizations using D3.js (v7+).

## 1. Key Implementation Patterns
- **Data Join & Enter-Update-Exit**: Use standard D3 `.join()` semantics for smooth DOM lifecycle transitions.
- **Responsive Scales**: Compute dynamic domains and SVG viewBox attributes to resize cleanly across screen resolutions.
- **Tooltips & Interactivity**: Implement hover tooltips with pointer coordinates, pointer-events optimization, and touch compatibility.
