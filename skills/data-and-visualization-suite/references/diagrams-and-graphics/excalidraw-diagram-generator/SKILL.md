# Excalidraw Diagram Generator Skill

Creates structured, hand-drawn aesthetic system architecture diagrams and workflows in Excalidraw JSON format.

## 1. Visual Layout Heuristics
- **Color Coding**: Blue for user-facing services, Green for business logic/compute, Purple for queues/events, Amber for databases/storage.
- **Clear Flow Direction**: Align components horizontally (Left-to-Right) or vertically (Top-to-Bottom) with labeled connector arrows.
- **Boundary Containers**: Enclose related microservices or cloud VPC boundaries in distinct bounding rectangles.
