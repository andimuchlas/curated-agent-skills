# Web Artifacts Builder Skill

Playbook for building self-contained, interactive web applications and UI prototypes.

## 1. Architecture Checklist
- **Self-Contained Bundling**: Include all necessary styles, Lucide icons, and interactive state in a cohesive component.
- **Modern Styling**: Utilize Tailwind utility classes with responsive breakpoints (`sm:`, `md:`, `lg:`).
- **State & Interactivity**: Provide dynamic filter controls, tab switching, and local storage state persistence where appropriate.
