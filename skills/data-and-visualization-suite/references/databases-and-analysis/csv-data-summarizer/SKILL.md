# CSV Data Summarizer Skill

Automates exploratory data analysis (EDA), anomaly detection, and statistical profiling on CSV datasets.

## 1. Automated Profiling Protocol
1. **Schema Inspection**: Column types, null counts, distinct value counts.
2. **Descriptive Statistics**: Mean, median, standard deviation, quartiles (p25, p50, p75, p99) for numerical features.
3. **Categorical Breakdown**: Top frequency distributions and cardinalities.
4. **Data Quality Flags**: Detect missing rows, duplicate primary keys, and outlier deviations.
