# PPTX Creator Skill

Playbook for generating professional PowerPoint decks using `python-pptx` and template systems.

## 1. Presentation Design Rules
- **16:9 Widescreen Aspect Ratio**: Standard modern layout format.
- **One Core Idea Per Slide**: Bold visual header + supporting 3-point bullet structure or metric card.
- **Speaker Notes**: Include conversational context and speaking talking points in the presentation notes metadata.
