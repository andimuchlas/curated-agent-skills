# PDF Toolkit Skill

A comprehensive playbook for PDF manipulation, text extraction, form handling, and document generation.

## 1. Capabilities & Tooling
- **Text & Table Extraction**: Use `pdfplumber` or `pypdf` for structured data recovery.
- **Document Assembly**: Merge, split, rotate, and encrypt/decrypt PDF streams.
- **Vector Document Generation**: Generate PDF reports using ReportLab or headless Chromium with print CSS stylesheets.
