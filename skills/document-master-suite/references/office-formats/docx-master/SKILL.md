# DOCX Master Skill

Guide for programmatic generation and manipulation of Microsoft Word documents using `python-docx` or office XML pipelines.

## 1. Document Structure Checklist
- **Styles & Hierarchy**: Define consistent Heading 1, Heading 2, Body Text, and Bullet List styles.
- **Table Formatting**: Explicit column widths, header row repeat on page breaks, and cell padding.
- **Page Layout**: Set margins (e.g., 1-inch standard), page numbers in footers, and section breaks.
