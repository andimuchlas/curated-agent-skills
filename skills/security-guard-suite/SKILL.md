# Security & Penetration Testing Suite

A unified framework for auditing codebases, hardening APIs, safeguarding AI agents, and conducting penetration testing against web services.

When securing or auditing code, locate the corresponding topic in `references/audits-and-hardening/<topic>/SKILL.md`.
